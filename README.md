## What is SecureCrack?
SecureCrack is a password guessing game. You type in passwords and you guess until you get it right. This is not completely impossible because you still have the option to get hints.

## Why build SecureCrack?
I was bored.

## Features:
- 3 password puzzles
- random password generator
- hints feature
- attempt counter
